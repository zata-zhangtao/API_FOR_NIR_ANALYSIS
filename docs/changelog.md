# 更新日志

本文档记录了 NIR API 的所有重要更改和版本发布信息。

## [1.0.0] - 2024-07-22

### 🎉 首次发布

这是 NIR API 的首个正式版本，提供了完整的近红外光谱分析功能。

### ✨ 新增功能

#### 核心模块
- **数据加载模块 (`load_data`)**
  - 支持从 MySQL 数据库加载光谱数据
  - Excel 文件处理和转换功能
  - 模型持久化（保存/加载）
  - 波长信息管理工具

- **数据预处理模块 (`preprocessing`)**
  - 标准正态变量变换 (SNV)
  - 多元散射校正 (MSC)
  - Savitzky-Golay 滤波
  - 基线校正方法
  - 异常值检测和移除

- **机器学习模块 (`ML_model`)**
  - 回归模型：PLSR, SVR, 随机森林, XGBoost 等
  - 分类模型：SVM, KNN, 决策树等
  - 特征选择：CARS, SPA, PCA 等
  - 数据分割和验证工具

- **数据可视化模块 (`draw`)**
  - 光谱图绘制功能
  - 模型性能可视化
  - PCA 分析图表
  - 交互式图表支持

- **数据分析模块 (`analysis`)**
  - 综合光谱数据分析
  - 异常值检测
  - 相关性分析
  - 统计报告生成

- **工具模块 (`utils`)**
  - 自动机器学习功能
  - 基于 Optuna 的超参数优化
  - 模型评估工具
  - 波长管理工具

#### 高级功能
- **分析类模块 (`AnalysisClass`)**
  - 光谱重建算法
    - 字典学习重建 (`SpectralDictionaryMapper`)
    - 神经网络重建 (`SpectrumTransformerByNN`)
    - 矩阵乘法重建 (`conv_MatMul_recon`)
    - 傅里叶变换重建 (`conv_DFT_recon`)
  - 模型评估器 (`SpectrumModelEvaluator`)
  - 高级重建方法

## 版本说明

### 版本号规则

NIR API 遵循 [语义化版本](https://semver.org/lang/zh-CN/) 规则：

- **主版本号**：不兼容的 API 修改
- **次版本号**：向下兼容的功能性新增
- **修订号**：向下兼容的问题修正

### 更新类型说明

- 🎉 **新增功能** - 新的特性和功能
- 🔧 **改进** - 现有功能的改进和优化
- 🐛 **修复** - 错误修复
- 📚 **文档** - 文档更新
- 🔒 **安全** - 安全相关的修复
- ⚠️ **废弃** - 即将移除的功能
- 💥 **破坏性变更** - 不向下兼容的修改

### 支持政策

- **当前版本 (1.0.x)**：完全支持，包括新功能和错误修复
- **前一个主版本**：仅提供关键错误修复和安全更新
- **更早版本**：不再提供支持

### 升级指南

升级到新版本时，请：

1. 查看本更新日志了解变更内容
2. 检查是否有破坏性变更
3. 更新您的代码以适应新的 API
4. 运行测试确保功能正常
5. 更新文档和依赖

如需帮助，请查看 [升级指南](development/upgrading.md) 或在 [GitHub Issues](https://github.com/zata/nirapi/issues) 中提问。
